# UI Konzept

## Hauptbereiche

Die App bleibt grob in zwei Bereiche aufgeteilt:

```text
Zeiten
Einstellungen
```

Später optional:

```text
Export
Diagnose
```

## Zeiten

Inhalte:

- Status-Kachel
- Start/Stop/Pause
- Tagesabschluss
- Tag/Woche/Monat/Jahr
- Zusammenfassung
- Eintragsliste

## Einstellungen

Inhalte:

- Geofence-Karte
- Radius
- Marker setzen
- Geofence registrieren/entfernen
- Arbeitszeitparameter
- Tagesabschlusszeit
- Export / Daten
- App Reset

## Export

Geplant für v0.8.0:

- Zeitraum auswählen
- CSV exportieren
- Dateidialog nutzen

## Designprioritäten

1. Aktiver Status muss sofort sichtbar sein
2. Einträge müssen gut lesbar sein
3. Bearbeiten/Löschen darf nicht versehentlich passieren
4. Geofence-Konfiguration muss klar visualisiert werden
5. Export und Reset gehören in getrennte Bereiche
