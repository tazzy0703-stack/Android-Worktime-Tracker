# Berechtigungen

## Standort

Erforderlich für:

- Geofence-Erkennung
- Arbeitsplatzbestimmung
- Automatischen Start
- Automatischen Stopp

## Benachrichtigungen

Erforderlich für:

- Foreground Service
- Statusanzeige während aktiver Arbeitszeit

## Hintergrundbetrieb

Je nach Android-Version können zusätzliche Akku-Optimierungen deaktiviert werden müssen, damit die Geofence-Erkennung zuverlässig arbeitet.

## Verwendete Berechtigungen

- ACCESS_FINE_LOCATION
- ACCESS_COARSE_LOCATION
- POST_NOTIFICATIONS
